# 성취기준별 모듈 설정 관리

모듈 하나는 성취기준 파일 하나로 관리한다. 파일 이름은 `12seji`와 성취기준 코드의 숫자를 이어 `12sejiNN-NN.js`로 쓴다. 예: `12seji01-01.js`.

## 모듈 계약

각 파일은 아래 필드를 포함한 객체를 기본 내보내기(default export)한다.

| 필드 | 용도 |
| --- | --- |
| `code`, `moduleId`, `group`, `title`, `time` | 교육과정 코드와 화면 분류 |
| `standardText` | 교육부 성취기준 원문 |
| `goal`, `concept`, `concepts`, `inquiryQuestion`, `activity` | 개념 설명과 질문·탐구 수업 |
| `artifact`, `rubric`, `sourceNote` | 학습 증거, 평가 관찰점, 자료 주의사항 |
| `digitalTools` | 이 모듈에서 실제로 쓰는 디지털 기능·라이브러리 |
| `ai` | AI 사용 상태·이유·실행 호출 횟수 |
| `visualization` | 시각화 유형, 자료, 상호작용 설정 |

모듈 등록 순서는 `index.js`에서만 바꾼다. 파일 이름, `code`, `moduleId`, 화면 메뉴에 표시되는 성취기준 순서를 맞춘다.

## AI 사용 값

- `status: 'not-used'`: 모듈이 AI를 사용하지 않는다. `rationale`과 `runtimeCallsPerLearner: 0`을 함께 둔다.
- `status: 'optional-not-connected'`: 04-02처럼 사전 산출 정적 자료를 향후 검토할 자리를 둔 상태다. 데이터 연결 전에는 화면에서 미연결임을 표시하고 실행 호출 수를 0으로 유지한다.
- 이 시제품에는 생성형 AI·학생별 API·RAG·자동채점 실행 코드가 없다. 정적 AI 산출물이 사용되는 경우에도 파일 출처, 사용권, 기준 시점, 분류 오차와 교사 검수를 기록한다.

## 시각화 유형

현재 `visualization.type` 값은 `src/components/visualizations/ModuleVisualization.jsx`에 렌더러가 등록되어 있다.

| 유형 | 기본 표시 기술 | 대표 성취기준 |
| --- | --- | --- |
| `flow-map`, `food-flow`, `timeline-map`, `gis-case`, `layer-map`, `story-map`, `peace` | MapLibre + 모식 GeoJSON, React 상호작용 | 장소·이동·시간·공간 자료 탐구 |
| `climate`, `population`, `food-systems`, `energy`, `environment` | Apache ECharts + 모식 값, 필요 시 지도 | 기후·인구·식량·에너지·환경 자료 읽기 |
| `value-chain` | MapLibre + Cytoscape.js 관계망 | 생산·유통·소비 관계 탐구 |

시제품 모식자료에는 실제 위치·경계·통계가 들어 있지 않다. 실제 자료로 교체할 때는 모듈 파일만 바꾸는 데 그치지 말고 출처·라이선스·기준연도·공간 단위·변수 정의를 자료 안내에도 기록한다. 외부 타일·데이터 서버를 연결하려면 별도의 자료·개인정보·비용 검토를 거친다.
