# 성취기준별 수업 모듈

각 `12sejiNN-NN.js`는 하나의 교육부 성취기준을 다루는 설정 파일입니다. 모든 파일은 `src/modules/index.js`에서 교육과정 순서로 등록합니다. 교과서 본문 데이터는 `src/content/units/`에서 별도 관리하고 `sectionIds`로 연결합니다.

## 필드

- `code`, `standardText`: 교육부 성취기준 코드와 문장
- `title`, `goal`, `concepts`: 모듈 이름과 학습 안내
- `sectionIds`: 함께 읽을 웹 학습 절 ID
- `qft`: 비질문형 초점 자료, 수업에서의 안내, 질문 생성부터 성찰까지의 시간 흐름
- `teacherGuide`: 준비물, 교실 진행 순서, 관찰·피드백 항목
- `digitalTools`, `visualization`: 해당 모듈에서 보여 줄 브라우저 기반 도구와 모식자료 설정
- `aiActivity`: 교사가 선택하는 외부 도구 활용 안내. API 호출이나 AI 코치 기능은 아님.
- `rubric`: 교과 성취와 질문 과정 피드백을 위한 관찰 기준

질문 초점은 학생이 질문을 만들기 전에 정답을 암시하는 질문 형태로 쓰지 않습니다. 실제 통계가 연결되지 않은 지도·차트는 모식자료로 표시합니다. 외부 AI 결과는 자료 출처로 인정하지 않으며, 사실 확인과 개인정보 주의 안내를 포함합니다.
