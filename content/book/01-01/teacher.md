# 교사용 안내

## 50분씩 5차시 시간 운영

- 1차시 여는 펼침면 QFT: 규칙 확인과 초점 지도 관찰 5분, 질문 만들기 10분, 닫힌·열린 질문 분류 8분, 질문 유형 바꾸기 8분, 중심 질문 선택 8분, 개념 태그와 자료 계획 8분, 다음 단계 안내 3분.
- 2차시 절 1: 생각 열기 기본 루틴으로 무역 연결 관찰 5분, 무역 지도 범례 확인 7분, 무역 시계열 비교 7분, 의류 수입 원산지 읽기 8분, 인터넷 이용률 변화 살피기 7분, Layer Compare 활동 10분, 루틴·활동 응답을 확인하고 질문에 근거 연결 6분.
- 3차시 절 2: 내 질문으로 자료 읽기 기본 루틴으로 전략 비교 5분, 지역화·지리적 표시 개념 확인 7분, 두 지역의 위치 찾기 5분, 관광 숙박일수 시계열 비교 10분, 세계지역화 개념도 읽기 7분, 가상 지역 브랜드 전략 활동 8분, 응답을 질문의 근거로 연결 8분.
- 4차시 절 3: 내 질문으로 자료 읽기 기본 루틴으로 다중 스케일 질문 살피기 5분, 무역·의류 자료 비교 12분, 인터넷 접근 차이 살피기 8분, 행위자와 결정 권한 나누기 6분, 가상 학교 구매 협의 활동 7분, 루틴·활동 응답을 근거 초안으로 확인·수정해 질문에 붙이기 7분, 기존 마무리 결과 파일 화면에서 질문·근거·설명 초안 JSON 내보내 제출 5분.
- 5차시 닫는 펼침면: 학생 초안을 작성한 같은 기기·브라우저에서 교사 피드백 파일 가져오기 5분, 핵심 개념 돌아보기 7분, 자료 근거로 설명 쓰기 8분, 피드백을 반영해 질문과 설명 다시 쓰기 12분, 남티롤 전이 과제 10분, 성찰 3분, 결과 파일 내보내기와 제출 안내 5분.

## 여는 펼침면 QFT 진행

- 질문 만들기·개선·우선화의 절차는 [Right Question Institute의 Question Formulation Technique(QFT)](https://rightquestion.org/what-is-the-qft/)를 교과서 흐름에 맞춰 적용한다. 학생이 만든 질문에서 시작하고, 예상 질문은 교사 참고용으로만 둔다.
- 질문을 가능한 한 많이 적는다. 만드는 동안 질문을 평가하거나 답하지 않고, 떠오른 진술은 질문 문장으로 바꾼다.
- 닫힌 질문과 열린 질문을 나누어 본다. 닫힌 질문은 짧은 사실로 답할 수 있고 열린 질문은 설명과 근거가 필요하다. 주어·범위·시점을 조정해 두 유형을 서로 바꾸어 본다.
- 이어갈 질문을 고른 뒤 관련 개념과 살펴볼 자료를 연결한다. 아래 예상 질문은 학생이 질문을 만든 뒤 교사 참고용으로 사용한다.
- 예상 학생 질문:
  - 무역 비중이 높으면 그 나라의 생활 수준도 높나요?
  - 세계 무역 비중이 늘면 모든 지역의 산업이 같은 방식으로 바뀌나요?
  - 인터넷을 쓰는 사람이 많으면 문화도 서로 비슷해지나요?
  - 의류 원산지 통계로 한 벌의 생산 경로를 알 수 있나요?
  - 지역 브랜드는 주민에게 어떤 선택을 남겨야 하나요?
  - 관광 숙박일수 변화만으로 지역 주민의 생각을 알 수 있나요?
  - 한 사람의 소비가 다른 지역과 연결되는 과정을 어떻게 확인할 수 있나요?

## 절 1 세계화의 의미와 영향

- 핵심 발문: 무역 비중과 무역액은 어떻게 다른가? 경제·정보 흐름은 각각 무엇을 연결하는가? 국제 분업의 역할과 이익을 더 알아보려면 어떤 자료가 필요한가?
- 자주 나오는 오개념: 무역 비중이 높은 나라가 반드시 더 부유하다고 본다. 수입 원산지를 한 상품의 전체 경로로 해석한다. 문화의 교류가 모두 획일화나 모두 다양화로 이어진다고 본다.
- 활동 운영: 지도·시계열·막대그래프의 단위와 범위를 각각 확인하게 한다. 선진국·개발 도상국이라는 큰 범주만으로 개별 산업과 노동자의 역할을 정하지 않도록 구체적인 품목·기업·노동 자료를 더 확인하게 한다.

## 절 2 지역화와 세계지역화

- 핵심 발문: 지역 브랜드와 지리적 표시제는 어떤 점에서 다른가? 세계적 방문 흐름이 지역의 산업과 생활에 닿는 경로는 무엇인가? 주민의 참여와 지역의 고유성을 함께 살리는 전략은 무엇인가?
- 자주 나오는 오개념: 지역화가 세계와의 교류를 끊는다고 본다. 숙박일수 증가를 곧바로 지역 주민의 이익으로 해석한다. 관광 통계만으로 변화 원인과 주민 의견을 정한다.
- 활동 운영: 대표 지점 지도는 집계 지역의 위치를 찾는 데 활용한다. 숙박일수는 숙박시설에서 보낸 밤의 합으로 읽고, 정책이나 주민 생활은 별도 근거가 필요하다고 안내한다. 가상 지역의 조건은 실제 통계로 오인하지 않게 한다.

## 절 3 다중 스케일과 세계시민

- 핵심 발문: 개인·지역·국가·세계의 결정은 어떻게 연결되는가? 수입 원산지와 무역 비중은 어떤 관계를 보여 주는가? 자료가 알려 주는 범위 안에서 각 행위자가 할 수 있는 행동은 무엇인가?
- 자주 나오는 오개념: 개인 선택만으로 구조적 문제를 해결할 수 있다고 본다. 지도 속 국가 평균을 모든 주민의 상황으로 확대한다. 수입 원산지를 노동 조건이나 생산 경로의 증거로 읽는다.
- 활동 운영: 협의회 역할은 학습용 가상 설정이라고 분명히 안내한다. 실제 자료에서 관찰한 사실과 역할 수행을 위해 가정한 상황을 분리하고, 역할에 따라 달라지는 정보와 결정 권한을 비교한다.

## 자료 읽기 주의점

- 무역 비중은 상품·서비스 수출입 합계의 국내총생산 대비 비율이다. 무역 총액·소득·생활 수준과 구분한다. 세계 무역 비중과 인터넷 이용률 시계열은 2024년까지 읽는다. 세계은행의 2025년 세계 집계는 잠정치 성격이 있어 그래프에서 제외했다.
- 인터넷 이용률은 인구 가운데 이용하는 사람의 비율이다. 콘텐츠의 종류와 디지털 이용 경험은 별도 자료로 살핀다. 지도나 시계열의 결측은 0으로 바꾸지 않는다.
- 미국 의류 자료는 일반수입에서 원산지별 HS 61–62류 금액을 집계한 통계다. 세계 의류 무역 전체·개별 상품의 경로·노동 조건을 보여 주는 자료로 확대하지 않는다.
- 관광 통계는 숙박시설에서 보낸 밤의 합이다. 방문객 수, 지역 경제 전반, 주민 의견이나 변화 원인을 직접 측정하지 않는다. 2021년 GISCO NUTS 지역 자료에서 계산한 점은 각 통계 지역의 대표 위치이며 행정 경계 자체가 아니다.
- GISCO 점 자료는 비상업적 사용 조건을 따르고, 행정 경계 출처를 표시한다. 자료 캡션에 © EuroGeographics (행정 경계)가 표시되는지 확인한다.
- 지리적 표시제는 상품과 장소의 연계를 나타내는 제도다. 지역 브랜드의 성과나 주민 참여 수준은 별도 사례 자료로 살핀다.

## 결과 파일 제출 안내

- 학생은 처음 만든 질문, 절별 근거와 활동 기록, 중심 질문에 대한 설명, 남티롤 전이 응답과 성찰을 결과 파일로 내보낸다. 실명 대신 별칭이나 학급 번호를 사용하고 교사가 안내한 LMS 제출함에 제출한다.
- 4차시 말 학생 결과 JSON에는 기록 ID가 포함된다. 교사는 교사용 화면(`#/teacher/01-01`)에서 해당 결과를 열고 질문별 코멘트를 적은 뒤 학생 표시명과 파일 식별용 짧은 접미사가 붙은 별도 피드백 JSON을 내려받는다. 파일은 직접 전달하며 자동 업로드하지 않는다.
- 기록 ID가 없는 이전 형식 결과는 열람만 가능하다. 학생이 초안을 작성한 같은 브라우저에서 결과 파일을 다시 내보내면 피드백 대상을 확인할 수 있다.
- 5차시 초 학생은 닫는 쪽의 교사 피드백 영역에서 파일을 가져온다. 원래 질문·설명은 자동으로 바뀌지 않는다. 학생이 피드백을 질문 또는 설명의 명시적 수정 기록에 연결한 뒤, 반영 또는 나중에 살펴보기와 이유를 기록한다. 다음 결과 JSON에 원코멘트와 변경 전후가 보존된다.
- 결과 파일에는 질문 이력과 외부 AI 링크를 연 시각이 담길 수 있다. 교사 피드백 파일에는 질문·설명 스냅샷과 질문별 코멘트가 들어간다. 보통 클릭으로 링크를 연 시각을 기록할 수 있지만, 가운데 클릭이나 링크 메뉴에서 새 탭을 여는 경우 등은 기록되지 않을 수 있어 기록 건수는 실제 링크 열기의 하한이다. 외부 대화 내용과 실제 사용 여부는 추적하지 않는다.
- 학생은 실명 대신 별칭이나 학급 번호를 사용한다. 파일을 사용하는 수업이 끝나면 교사는 결과·피드백 파일을 삭제한다. 파일을 연구 자료로 사용하려면 연구 계획, 동의 절차, 기관 심의를 먼저 마쳐야 한다.

## 생각 루틴

- 각 절의 생각 열기와 「내 질문으로 자료 읽기」 앞부분, 「내 질문과 이 절」에 [Project Zero Thinking Routines](https://www.pz.harvard.edu/thinking-routines)를 바탕으로 한 생각 루틴 카드가 있다. 칸마다 한두 문장이면 충분하며, 루틴 하나에 5분 안팎을 쓴다. 학생용 우리말 질문은 교과서에서 새로 썼고 응답은 필수가 아니다.
- 파일럿 기본 화면은 절 1의 생각 열기 루틴, 각 절의 선택 질문과 탐구 활동, 절 2·3의 내 질문으로 자료 읽기 기본 루틴으로 구성한다. 탐구 활동은 펼친 핵심 과제로 둔다. 각 절의 짧은 정리 루틴도 펼쳐 두고, 기본이 아닌 생각 루틴은 접힌 선택 항목이다. 선택한 질문은 읽기 전용으로 보이고, 루틴·활동의 실제 응답을 근거 초안에 불러와 학생이 확인·수정한 뒤 질문에 붙일 수 있다. 원응답은 그대로 보존된다.
- 4차시 말에는 기존 마무리의 결과 파일 화면에서 학생 초안 JSON을 내보낸다. 교사는 차시 사이에 확인해 교사 피드백 파일을 만든다. 5차시 시작 때 학생은 초안을 작성한 같은 기기·브라우저에서 교사 피드백 파일을 불러와 질문과 설명을 다시 쓴다.
- 생각 열기의 「궁금한 것」류 칸은 「질문 목록에 넣기」로 중단원 질문 목록에 보낼 수 있다. 마무리 쪽 질문 다듬기에서 다시 다룬다.
- 절 1: 생각 열기 See, Think, Wonder(보고·생각하고·궁금해하기, 기본) · 내 질문으로 자료 읽기 The 3 Whys(세 가지 왜, 선택) · 정리 I Used to Think… Now I Think…(예전 생각·지금 생각, 선택)
- 절 2: 생각 열기 Think, Puzzle, Explore(생각·궁금증·탐색, 선택) · 내 질문으로 자료 읽기 Options Diamond(선택지 다이아몬드, 기본) · 정리 I Used to Think… Now I Think…(예전 생각·지금 생각, 선택)
- 절 3: 생각 열기 Compass Points(나침반 네 방향, 선택) · 내 질문으로 자료 읽기 Step In, Step Out, Step Back(들어가 보기·물러나 보기·돌아보기, 기본) · 정리 I Used to Think… Now I Think…(예전 생각·지금 생각, 선택)
