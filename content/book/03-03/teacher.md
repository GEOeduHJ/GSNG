# 교사용 안내

## 50분씩 5차시 시간 운영

- 1차시 여는 펼침면 QFT: 투자 지도 조용히 관찰 5분, 규칙 안내 3분, 질문 만들기 12분, 닫힌·열린 질문 분류 8분, 질문 유형 바꾸기 8분, 중심 질문 선택과 개념 태그 9분, 다음 단계 계획 5분.
- 2차시 절 1: 중심 질문 다시 보기 5분, 초국적 기업과 가치사슬 읽기 8분, FDI 지도 읽기 10분, 세계 FDI 시계열 읽기 10분, 가치사슬 단계·입지 조건 분류 12분, 근거와 자료 한계 정리 5분.
- 3차시 절 2: FDI 지도 범례 확인 5분, 1인당 GDP 지도 비교 10분, 상수 PPP 시계열 읽기 10분, 극빈율 지도의 국가별 연도 확인 10분, 공간 패턴 비교와 원인 토의 10분, 근거 기록 5분.
- 4차시 절 3: ODA 수원 지표의 분모·방향 확인 7분, ODA 지도 읽기 10분, 수원액 시계열 읽기 10분, 국제 협력과 책임 기준 확인 8분, 가상 매점 청문회 12분, 근거와 추가 확인 정보 정리 3분.
- 5차시 닫는 펼침면: 핵심 개념과 자료 한계 정리 7분, 중심 질문에 근거를 연결한 설명 쓰기 12분, 질문 다시 다듬기 7분, 스마트폰 가치사슬 전이 과제 15분, 돌아보기 4분, 결과 파일 내보내기와 제출 안내 5분.

## 여는 펼침면 QFT 진행

- 규칙 안내 말: 가능한 한 많은 질문을 적는다. 쓰는 동안 질문을 평가하거나 답하거나 고치지 않는다. 질문이 아닌 생각은 질문 문장으로 바꾸어 적는다.
- 학생이 먼저 질문을 만든 뒤 닫힌 질문과 열린 질문으로 분류한다. 닫힌 질문은 예·아니요나 짧은 사실로 답할 수 있고, 열린 질문은 설명과 근거가 필요하다. 질문의 대상·범위·조건을 바꾸어 두 유형을 서로 바꾸어 본다.
- 질문 유형에 우열을 두지 않는다. 탐구에 필요한 질문을 고르고 관련 개념과 자료 계획을 정한다. 아래 예상 질문은 학생의 첫 질문 만들기가 끝난 뒤에만 교사 참고용으로 사용한다.
- 예상 학생 질문:
  - 외국인 직접 투자가 많이 들어온 나라는 글로벌 가치사슬에서 더 많은 이익을 얻나요?
  - 같은 상품의 설계와 조립은 왜 서로 다른 곳에서 이루어질 수 있나요?
  - 1인당 GDP가 높으면 그 나라 사람들의 소득도 모두 높은가요?
  - 빈곤율 지도에서 같은 색인 나라들은 같은 해의 자료인가요?
  - 원조를 많이 받은 나라에서는 빈곤이 반드시 줄어드나요?
  - 공정무역 인증이 있으면 모든 생산자의 노동 조건을 알 수 있나요?
  - 소비자의 선택과 기업·정부의 책임은 어떻게 이어지나요?

## 절 1 글로벌 경제와 가치사슬

- 핵심 발문: 초국적 기업의 여러 기능은 어떤 입지 조건과 관련될 수 있는가? FDI 지도와 시계열은 무엇을 측정하는가? 투자 흐름만으로 생산 단계나 가치의 배분을 설명할 수 있는가?
- 자주 나오는 오개념: FDI 유입률이 높으면 초국적 기업의 영향력이나 국내 부가가치가 반드시 크다고 본다. 한 상품의 모든 생산 단계가 같은 나라에 있다고 생각한다. 세계화가 각 지역에 같은 역할과 이익을 준다고 본다.

## 절 2 공간적 불균등의 분포와 원인

- 핵심 발문: FDI/GDP와 1인당 GDP 지도는 각각 어떤 분모와 단위를 쓰는가? 1인당 GDP와 극빈율의 공간 패턴은 어디서 함께 보이거나 달라지는가? 역사·교역 조건·기술·제도 가운데 어떤 자료가 더 있어야 원인을 설명할 수 있는가?
- 자주 나오는 오개념: 현재 PPP 지도와 상수 PPP 시계열의 숫자를 직접 비교한다. 국가 평균을 개인 소득으로 해석한다. 빈곤율 지도 전체가 같은 연도라고 읽거나 결측을 0으로 본다. 두 지표의 상관을 원인과 결과로 단정한다.

## 절 3 불균등을 줄이는 협력과 실천

- 핵심 발문: ODA 지도와 시계열은 수원국의 어떤 측면을 보여 주는가? 공정무역 기준은 무엇을 약속하고 제품별로 무엇을 더 확인해야 하는가? 학교·기업·공공기관·소비자는 각각 어떤 결정 권한과 책임을 가지는가?
- 자주 나오는 오개념: ODA 수원 비율을 공여국의 원조 노력이나 사업 효과로 읽는다. 인증 상품의 기준만 확인하고 해당 제품의 실제 공급 경로·가격·성과까지 안다고 여긴다. 공간적 불균등의 책임을 소비자 개인에게만 돌린다. 가상 역할의 발언을 실제 생산자나 보호자 집단의 의견으로 일반화한다.

## 자료 읽기 주의점

- FDI 지도는 2024년 순유입액/GDP 비율이고 세계 시계열은 현재 US$ 순유입액이다. 유입률은 절대액이나 초국적 기업 활동·글로벌 가치사슬 참여·국내 부가가치를 직접 측정하지 않으며, 현재 달러 시계열은 물가 조정 실질액이 아니다.
- 1인당 GDP 지도는 2024년 현재 PPP 기준 국가 간 비교 자료다. 선그래프는 2021년 상수 PPP 기준으로 1990–2024년의 변화를 읽는다. 목적이 다른 두 PPP 값을 섞지 않고, 1인당 GDP를 개인이나 가구의 소득으로 해석하지 않는다.
- 극빈율 지도는 하루 3.00달러(2021 PPP) 선 아래 인구 비율이며 국가별 최신 관측 연도가 2015–2023년으로 다르다. 캡션과 각국의 observationYears를 확인하고 같은 해 자료처럼 비교하지 않는다. 이전 2.15달러(2017 PPP) 판과 직접 비교하지 않는다.
- ODA 자료는 수원국이 받은 순액이다. 지도는 2023년 순 수원액/GNI 비율, 시계열은 상수 2023 US$이며, 비율과 절대액을 구분한다. 음수 순액이 가능하다. 자료는 공여국별 ODA/GNI, 분야, 사업 성과나 원조의 인과 효과를 보여 주지 않는다.
- OECD TiVA는 가치사슬의 부가가치 참여를 분석하는 지표를 제공하지만 이번 단원에 가공 수치는 없다. FDI 자료를 GVC 참여 자료로 대체하지 않는다. 기업별 실제 공급 경로를 다룰 때에는 기업·국제기구의 원문 자료를 별도로 확인한다.
- UNCTAD와 World Bank 보고서는 불균등과 무역의 여러 구조적 요인을 다룬다. 국가 지도 한 장이나 사례 하나를 모든 나라의 원인으로 일반화하지 않는다.
- 가상 매점 청문회는 실제 학교나 협동조합의 입장, 판매 가격, 공급량을 재현하지 않는다. 학생이 허구 상황을 토론할 때 사실 자료와 역할을 위해 가정한 조건을 구분하게 한다.

## 결과 파일 제출 안내

- 학생은 질문, 자료 근거, 설명, 다듬은 질문, 스마트폰 가치사슬 전이 응답을 결과 파일로 내보낸다. 실명 대신 학급 번호나 별칭을 사용하고, 교사가 안내한 LMS 제출함에 직접 제출한다.
