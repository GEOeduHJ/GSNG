# 세계시민과 지리 웹 재구성형 디지털 교과서 설계

## 의도

고등학교 「세계시민과 지리」 학습자가 교과서 순서로 본문을 읽고, 지도·차트·모형을 조작하며, 성취기준별 질문 기반 지리 탐구를 수행할 수 있는 공개형 웹 교과서를 만든다. 기존 React 시제품을 확장하는 수준에 머무르지 않고, 책의 목차 구조와 13개 성취기준을 한 교과서 경험 안에서 연결한다.

## 확정된 선택

- 사용자는 PDF 뷰어·페이지 이미지 방식이 아닌 웹 재구성을 선택했다.
- 4개 대단원, 13개 중단원, 41개 번호 학습 절의 순서와 범위를 탐색 구조에 반영한다.
- 본문 설명, 자료 해설, 사례, 문항, 시각 자산은 새로 작성·제작한다. 교과서 본문이나 고유 문항을 옮기거나 가깝게 바꿔 쓰지 않고, 제3자 사진·도판도 포함하지 않는다. 교육부 성취기준과 공개 출처를 토대로 원고를 독립 집필한다.
- 성취기준 13개 각각은 별도의 `src/modules/12sejiNN-NN.js`에서 설정 데이터로 관리하고, 교과서 절 콘텐츠는 대단원별 별도 파일로 둔다. QFT 화면은 독립 경로로 노출하지 않고 관련 교과서 절 안에 접고 펼치는 영역으로 포함한다.
- QFT(Question Formulation Technique)는 성취기준과 연결된 교과서 본문 안에서 완전한 수업 흐름으로 제공한다. 질문 생성은 제한 없이 추가 가능하고, 질문 분류·양방향 변환·우선화·근거 탐색·주장과 추론·성찰을 기록한다. 4단계에서 관련 교과서 절로 이동해도 QFT와 작성 기록이 열린 채 유지된다. 설계자 예시 질문은 학생 생성 전에 노출하지 않는다.
- 생성형 AI 코치, 사이트 내 생성형 AI API, 자동 채점, 서버 계정과 교사 데이터 대시보드는 만들지 않는다. 외부 AI 사용은 교사가 선택하는 외부 도구 보조 활동 안내에 그치며 필수 단계가 아니다. 계정·가격·개인정보 조건은 제공자 정책을 따르며 사용 전에 표시한다.
- 학습 기록은 기본적으로 현재 브라우저의 `localStorage`에만 저장하고 학생이 JSON으로 내려받을 수 있게 한다. 전송·동기화·연구 자료 수집은 하지 않는다.

## 목표

1. 4개 대단원, 13개 중단원, 41개 학습 절과 단원 마무리를 목차에서 찾을 수 있다.
2. 모든 학습 절에 독립 작성한 설명 본문, 핵심 개념, 학습 적용 과제, 출처를 제공한다.
3. 13개 성취기준에서 각각 관련 절, QFT 초점, 교사용 수업 안내, 자료 탐구, 학생 평가 산출물이 해당 교과서 본문 안에서 연결된다.
4. 지도와 관계망은 로컬 공개·모식 자료, 차트는 표시된 데이터 출처를 사용한다. 실측 지형이 없는 3D 장면은 개념 모형으로 명시한다.
5. 학생이 키보드, 모바일, 확대 화면으로 목차·본문·QFT를 이용할 수 있다.
6. 일반 공개 전에 원고와 시각자료의 출처·라이선스·처리 상태를 확인할 수 있게 기록한다.

## 제외 범위

- 원본 PDF, 페이지 스크린샷, 교과서 사진·지도·문항을 브라우저에 제공하거나 저장소에 포함하는 기능.
- 로그인, 학급 공유, 여러 기기 동기화, 교사 서버 대시보드, 연구용 개인자료 수집.
- Gemini·Suno·기타 생성형 AI로 웹 안에서 문장이나 답을 생성하는 API 통합.
- 콘텐츠 제작자가 교과서 전체와 동일한 서술·사례 구성을 복제하는 것. 웹 본문은 독립 집필이며, 교과서에 실린 사실·개념의 교육과정상 범위를 폭넓게 다룬다.

## 접근 방식

1. **웹 재구성형(선택):** 교과서의 학습 구조를 목차와 내부 편집 대조표로 반영하되, 본문과 자료·활동을 웹용으로 독립 작성한다. React 데이터로 분리하면 수업 도구와 13개 기준 연결을 계속 수정할 수 있다.
2. **PDF 뷰어/페이지 이미지 하이브리드(기각):** 빠르게 원본과 동일한 외형을 제공하지만 이번 사용자가 거부했으며, 원본 표현과 제3자 시각자료의 온라인 재배포 문제가 남는다.
3. **성취기준 카드만 유지(기각):** 기존 시제품을 조금 고치는 비용은 적지만 41개 학습 절을 가진 디지털 교과서 목표를 충족하지 못한다.

## 정보 구조와 학습 경험

- 시작 화면 → 대단원 선택 → 중단원/41개 절 → 웹 본문과 시각 자료 → 같은 교과서 절 안의 QFT → 산출물·성찰.
- 자유 읽기와 QFT 진입을 모두 제공한다. 자유 읽기에서는 목차대로 학습 절에 접근한다. 교과서 절의 QFT 버튼은 새 화면을 열지 않고 본문 아래의 QFT 영역으로 이동한다. QFT 4단계에서 교과서 절을 고르면 해당 본문으로 이동하며, 열린 QFT와 작성 기록은 유지되고 상단 바로가기로 탐구 영역에 돌아간다. QFT는 비질문형 현상·지도·이미지를 초점으로 시작하고, 질문 생성 전에는 사례의 예시 질문을 가린다.
- 13개 성취기준 모듈은 관련 학습 절 여러 개를 가로질러 연결될 수 있다. 한 절은 내용상 둘 이상의 성취기준을 지원할 수 있다.
- 본문은 절마다 `도입`, `설명`, `개념`, `장소/사례`, `자료 읽기`, `활동`, `요약`, `출처` 데이터 블록으로 구성한다. 각 절은 한두 문장의 요약 카드가 아니라 수업에서 읽고 활동할 수 있는 독립 원고여야 한다.
- 3D 지형 표현은 기존 실측 DEM이 없는 동안에는 직접 만든 개념 모형으로 한정하고, 실제 장소의 지형이나 계측 자료로 오인되지 않도록 표시한다.

## 데이터 및 구현 구조

- `src/content/units/unit-01.js` … `unit-04.js`: 대단원 정보, 중단원과 41개 학습 절, 독립 집필 본문, 과제, 출처, 시각화 타입.
- `src/content/bookIndex.js`: 4개 대단원/13개 중단원/41개 절 탐색 인덱스와 콘텐츠 ID 검증.
- `src/modules/12sejiNN-NN.js`: 공식 성취기준, 관련 section IDs, 학습 목표, QFT 초점, 수업 흐름, 평가기준, 교사 안내, 무비용 디지털 선택 도구.
- `src/components/`: 책 목차, 읽기 페이지, 콘텐츠 블록, QFT 단계, 학습 기록, 교사 안내 등 기능 단위 React 컴포넌트.
- `src/components/visualizations/`: MapLibre GL JS, Apache ECharts, Cytoscape.js 및 자체 SVG 지리 개념 모형.
- 정적 웹 사이트, 기존 React/Vite와 설치된 오픈소스 라이브러리를 유지한다. 새 서비스 백엔드나 유료 외부 의존성은 도입하지 않는다.

## 시각·접근성 원칙

- 교육 서비스답게 명료한 대비, 한 단계짜리 목차 계층, 읽기 쉬운 본문 폭, 모바일 우선 재배열을 쓴다.
- 표준 HTML 제목·landmark·label을 사용하고, 키보드 포커스를 표시한다. 지도·차트·3D는 텍스트 설명 또는 표 대안을 제공한다.
- 모식자료와 실제 통계자료의 표시를 구분하고, 단위·시기·공간 범위·출처를 함께 제공한다.
- 외부 타일·API 호출은 피한다. 꼭 필요한 콘텐츠 링크는 출처와 제공기관으로 이동할 수 있게 한다.

## 공개와 연구상의 경계

저장소 공개에는 새로 작성한 원고, 자체 제작한 도식, 재사용 조건을 확인한 데이터만 포함한다. 공개 전 각 콘텐츠 블록에 출처 URL, 제작기관, 자료 시점, 라이선스/사용 근거, 검토 상태를 기록한다. 사용자가 제공한 교과서는 내부 교육과정·주제 대조 자료로만 사용하며 공개 코드·정적 사이트에 포함하지 않는다. 학습 기록은 브라우저 밖으로 보내지 않는다. 본 서비스는 아직 전문가 내용 타당도 검토나 학생 대상 효과 검증을 받은 연구 도구가 아니다.
