# 소절 학습 모듈 재구성 설계

작성: 2026-11-27 · 상태: 연구자 승인 대기 · 선행 설계: `2026-11-26-textbook-v2-redesign-design.md`

## 1. 왜 바꾸나(연구자 판단)

연구자가 v2 화면을 직접 검토하고 세 가지 문제를 지적했다.

1. **스크롤 연동이 본문과 어긋난다.** 스크롤하면 오른쪽 자료가 바뀌는 방식 자체는 좋았다. 그러나 지금 읽는 문장과 오른쪽 자료가 맞지 않는 경우가 많다.
2. **본문이 학습 내용이 아니라 자료 개요다.** 문단 5개가 자료 5개에 하나씩 묶여 있어서, 문단마다 "이 자료는 무엇을 보여 준다"는 소개가 된다. 교과서처럼 개념을 가르치는 글이 아니다.
3. **소절이 완결된 학습 모듈이 아니다.** 지도와 통계를 차례로 소개할 뿐이다. 학습에서 시작해 탐구를 거쳐 질문 정리로 끝나는 흐름이 없다. 「내 질문과 이 절」도 자료 옆에 섞여 있어 마무리 단계로 보이지 않는다.

## 2. 목표·비목표·피해야 할 것

**목표**
- 각 소절을 『고등학교 세계시민과 지리』(천재교과서) 해당 소절의 학습 목표와 소주제 흐름에 맞춰 다시 쓴다. 소주제마다 개념을 설명하는 교과서 본문을 둔다.
- 본문의 개념을 실제 공개 자료로 탐구하도록, 관련 문장 바로 옆에 **「자료 보기」 버튼**을 단다. 누르면 오른쪽에 그 자료가 나타난다.
- 소절 하나가 「학습 → 탐구 → 정리 → 질문」으로 끝나는 완결된 모듈이 되게 한다.
- 교과서 소주제에 맞는 실제 자료가 없으면 **새 실제 공개 자료를 수집해 추가한다**(연구자 결정).

**비목표**
- 교과서 문장·그림·도표를 옮기지 않는다. 소주제의 순서와 다루는 개념만 따르고, 문장은 새로 쓴다. 교과서가 인용한 자료 수치도 옮기지 않는다. 같은 지표를 원 출처에서 직접 받는다.
- 중단원 여는 쪽·마무리 쪽의 QFT 흐름은 바꾸지 않는다.
- 이번 범위에서 새 활동 템플릿은 만들지 않는다. 기존 4종(LayerCompare, EvidenceSort, DecisionMatrix, CivicHearing)을 쓴다.

**피해야 할 것(이렇게 되면 실패)**
- 본문이 다시 자료 설명문이 되는 것. 문단은 개념 설명으로 시작하고, 자료는 그 개념을 확인하는 수단이어야 한다.
- 버튼을 눌렀을 때 문장과 상관없는 자료가 뜨는 것
- 스크롤만으로 오른쪽 자료가 바뀌는 것
- 수치나 출처를 지어내는 것. 「수치는 실제, 상황은 허구」 원칙은 그대로다.

## 3. 접근 방식

| 안 | 내용 | 장단점 | 결정 |
| --- | --- | --- | --- |
| **1안: 펼침면은 학습, 아래 구역은 탐구·정리·질문** | 위 펼침면에서는 왼쪽에 소주제 본문, 오른쪽에 선택한 자료를 둔다. 그 아래 화면 전체 폭으로 탐구하기 → 핵심 정리 → 내 질문과 이 절을 둔다. | 학습과 마무리 단계가 눈에 띄게 나뉜다. 활동이 전체 폭을 쓴다. | **연구자 선택** |
| 2안: 모든 것을 펼침면 안에 | 탐구하기·정리를 왼쪽 흐름에 잇고, 활동을 오른쪽에 띄운다. | 책 느낌은 강하다. 그러나 활동이 반쪽 폭에 갇히고, 활동하는 동안 자료를 볼 수 없다. | 채택 안 함 |
| 스크롤 연동 개선 | 문단과 자료의 대응을 더 정밀하게 맞춘다. | 근본 문제(자료 중심 본문)가 남는다. | 연구자가 버튼 방식을 원해 제외 |

## 4. 소절 화면(연구자 결정 + 세부는 설계자 판단)

```
┌ 왼쪽 본문 ─────────────────────┬ 오른쪽 자료 ─────────────┐
│ 03-01 · 절 2                     │                            │
│ 인구 구조의 변화는 어떤 인구 문제를 가져올까? │  [선택한 지도·그래프]        │
│ 학습 목표                        │  캡션 · 출처                │
│ 생각 열기: 짧은 도입 질문 1개      │  "소주제 2와 연결된 자료"     │
│                                  │  (화면에 고정)               │
│ ■ 소주제 1 제목                  │                            │
│   개념 설명 문단 …                │                            │
│   [자료 보기 ▸ 세계 인구 증가]     │                            │
│ ■ 소주제 2 제목                  │                            │
│   개념 설명 …  [자료 보기 ▸ …]    │                            │
│ ■ 소주제 3 …                     │                            │
│ 핵심 용어                        │                            │
└──────────────────────────┴────────────────────┘
━━ 탐구하기 ━━ 실제 자료로 하는 활동(화면 전체 폭)
━━ 핵심 정리 ━━ 이 절의 핵심 개념 3–4줄
━━ 내 질문과 이 절 ━━ ① 내 질문에 근거 붙이기 ② 이 절을 마치며 새로 생긴 질문
```

**오른쪽 자료 영역(설계자 판단)**
- 처음 열면 첫 소주제의 첫 자료를 보여 준다.
- 「자료 보기」를 누르면 그 자료로 바뀐다.
- 누른 버튼은 「보는 중」으로 표시한다(`aria-pressed`).
- 자료 영역 제목에는 어느 소주제와 연결된 자료인지 적는다.
- 스크롤로는 바뀌지 않는다. 지도 확대·이동 상태는 자료를 바꿀 때만 초기화한다.

**좁은 화면(1024px 미만, 설계자 판단)**
- 오른쪽 영역이 없다. 「자료 보기」를 누르면 그 문단 바로 아래에 자료가 펼쳐지고, 다시 누르면 접힌다(`aria-expanded`).
- 여러 자료를 동시에 펼칠 수 있다.

**한 버튼, 한 자료(설계자 판단)**
- 버튼 하나는 자료 하나를 연다. 자료 하나에 버튼이 여러 개 있어도 된다.
- 한 소주제에 버튼이 없어도 된다(개념 설명만 있는 소주제).
- 다만 소절 전체에서 모든 자료는 적어도 한 번 버튼으로 연결되어야 한다.

## 5. 소절 모듈 구성과 글쓰기 기준

| 부분 | 내용 | 분량 기준(설계자 판단) |
| --- | --- | --- |
| 학습 목표 | 교과서 해당 소절의 학습 목표 취지를 따르되 문장은 새로 쓴다. | 1문장 |
| 생각 열기 | 학생 생활이나 뉴스와 이어지는 도입 질문 | 1–2문장 |
| 소주제 | 교과서 소절의 소주제 순서를 따른다. 각 소주제는 개념 정의 → 원리·까닭 → 사례 → 자료로 확인할 점 순서로 쓴다. | 소주제 2–5개, 각 1–3문단 |
| 자료 보기 | 문단 끝에 둔다. 버튼 이름은 무엇을 보는지 짧게 적는다(예: "세계 인구 증가 그래프"). 버튼 앞 문장은 자료에서 무엇을 확인할지 안내한다("~를 비교해 보자"). | 소절당 자료 3–7개 |
| 탐구하기 | 기존 활동(`activity`)을 이 자리로 옮긴다. 본문에서 배운 개념을 자료에 적용하는 과제다. | 1개 |
| 핵심 정리 | 이 절에서 배운 개념을 학생이 다시 읽을 문장으로 정리한다. | 3–4항목 |
| 내 질문과 이 절 | ① 여는 쪽에서 고른 질문에 이 절의 자료로 근거 붙이기(기존 기능). ② **이 절을 마치며 새로 생긴 질문 적기(새 기능)**: 적은 질문은 중단원의 질문 목록에 들어가고, 마무리 쪽 「질문 고쳐 쓰기」에서 다시 볼 수 있다. | — |

**글쓰기 기준**
- 본문은 교과서 서술처럼 일반 개념을 설명한다. 특정 수치는 개념을 확인하는 사례로만 쓴다. 문단을 "이 자료는…"으로 시작하지 않는다.
- 자료의 한계는 지금처럼 절마다 필요한 것만 한 번 밝힌다.
- `content/textbook-style.md`(문체 지침)는 유지하고, 위 기준을 「본문 구성」 절로 추가한다.

## 6. 내용 근거와 새 자료

**교과서 대응**
- 교과서 41개 소절과 우리 41개 절은 제목·학습 목표가 일대일로 대응한다(교과서 PDF 4–208쪽의 「학습 목표」에서 확인).
- 소절별로 교과서의 소주제 목록과, 각 소주제가 쓰는 자료의 종류만 기록한다. 예: 03-01 2절은 세계 인구 성장 → 인구 변천 → 연령층별 인구 구조 → 산업별 인구 구조 → 지역별 인구 문제.
- 이 대응표는 `content/textbook-map/<중단원>.yaml`에 쪽수와 함께 둔다. 문장은 옮기지 않는다.

**자료 수집 규칙**
- 기존 자료는 소주제에 맞으면 다시 쓴다.
- 맞는 자료가 없으면 실제 공개 자료를 새로 수집한다. 규칙은 기존과 같다.
  - 스크립트: `scripts/data/<중단원>/`
  - 기록: manifest·출처 기록·README 대조표
  - 이용 조건 확인, 결측 보존, 잠정치 제외
- 03-01에서 예상되는 새 자료는 다음과 같다. World Bank WDI와 UN WPP이며, 모두 CC BY 계열이다.
  - 세계 인구 증가 추이·전망
  - 조출생률·조사망률
  - 유소년·노년 부양비
  - 산업별 종사자 비율
  - 순이동
- **실제 자료로 만들 수 없는 교과서 개념은 「개념도」로 표시한 도식으로 둔다.** 예: 인구 변천 모형. 이미 있는 `schematic` 표시를 쓰고, 실제 수치처럼 보이지 않게 한다.

## 7. 콘텐츠 형식(설계자 판단)

`lesson-N.md` 머리말(YAML)과 본문을 다음처럼 바꾼다.

```markdown
---
title: …
goal: …
opener: 생각 열기 문장
steps:            # 자료만 둔다(text 단계는 없앤다)
  - { id: d1, type: chart, data: …, label: 세계 인구 증가 그래프, caption: …, source: …, alt: …, config: … }
summary: [핵심 정리 1, 핵심 정리 2, 핵심 정리 3]
textbookRef: { pages: [128, 131] }
activity: …       # 탐구하기(기존 형식 유지)
keyTerms, sourceIds, illustration   # 기존 유지
---
## 세계 인구 성장
문단 … 자료에서 산업 혁명 이후의 변화를 확인해 보자. [[d1]]

문단 …

## 인구 변천
…
```

- **본문 형식**
  - `## 제목`은 소주제가 된다.
  - `[[자료id]]`는 그 자리에 「자료 보기」 버튼이 된다. 버튼 이름은 자료의 `label`이고, 없으면 `caption`을 쓴다.
- **구조 검사(`check:book`) 규칙**
  - 소주제 2–5개, 자료 3–7개
  - 모든 `[[id]]`가 존재하고, 모든 자료가 한 번 이상 연결되어야 한다.
  - `summary` 3–4항목, `opener`가 있어야 한다.
  - 문단 4–6개, 문단 수와 단계 수 일치 같은 옛 규칙은 새 형식에 적용하지 않는다.
- **전환기 호환**
  - 옛 형식 절(소주제 없음)도 같은 새 화면으로 보여 준다. 문단 i 끝에 단계 i의 「자료 보기」 버튼을 자동으로 붙인다.
  - 따라서 **화면 변경을 먼저 반영하면 41개 절 모두에서 스크롤 연동이 즉시 사라진다.** 본문 재작성은 중단원별로 이어서 한다.
- **학생 기록**
  - 저장 형식은 v4를 유지한다.
  - 새로 생긴 질문은 별도 목록을 만들지 않고 중단원의 질문 목록(`record.questions`)에 넣는다. 어느 절에서 나왔는지(`fromLessonId`)를 남기며, 옛 기록에는 이 값이 없어도 된다.
  - 새 질문은 처음에는 선택되지 않은 상태이고 분류도 비어 있다.
  - 여는 쪽 질문 목록에는 「학습 중 생긴 질문」 표시와 함께 보이며, 우선 질문으로 고를 수 있다.
  - 결과 파일에도 그대로 실린다.
  - 마무리 쪽 「질문 다시 다듬기」에서는 학습 중 생긴 질문을 참고 목록으로 보여 준다. 학생이 하나를 골라 다듬을 질문 칸으로 불러올 수 있다. `revisedQuestion`의 의미는 「최종으로 다듬은 질문」 그대로다.
  - 아직 실제 수업에서 쓴 학생 기록은 없다(학교 적용 전). 따라서 자료 id를 새로 정해도 된다. 옛 근거 기록에서 자료 id를 찾지 못하면 근거 메모만 보여 준다.
- **개념도**
  - 실제 수치로 그릴 수 없는 개념(예: 인구 변천 모형)은 Codex가 만든 SVG 도식 이미지로 둔다.
  - 단계 형식은 `type: image, schematic: true`이고, 기존 삽화처럼 출처 기록(provenance)을 남긴다.
  - 캡션 앞에는 「개념도」라고 표시한다. 수치 축이나 실제 값처럼 보이는 눈금은 넣지 않는다.
  - 자료 3–7개 범위에 포함하되, 소절마다 실제 자료가 3개 이상 있어야 한다.
- **교과서 쪽수(`textbookRef`)**
  - 내부 검사와 작업 기록에만 쓰고, 학생·교사 화면에는 보이지 않는다.
- **없애는 것**
  - 스크롤 연동 코드(`useActiveStep`, 작업 구역 감시, 「본문과 다시 맞추기」 버튼, `stage-track`)

## 8. 진행 순서(연구자 결정 + 설계자 판단)

1. **화면 골격:** 버튼 방식, 아래 구역, 새 형식 해석과 검사, 옛 형식 호환, 새 질문 기능. 테스트를 먼저 쓴다.
2. **시범 중단원 03-01(절 3개):** 교과서 대응표, 새 자료 수집, 본문 재작성, 탐구하기·정리, 교사용 안내 갱신.
   - 이 세션이 지금까지처럼 `codex exec`로 Codex(gpt-6-luna, max)를 호출한다.
   - Codex는 교과서 대응표, 자료 스크립트와 자료 파일, 개념도 SVG, 본문 초안을 만든다.
